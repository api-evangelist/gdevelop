# GDevelop

> GDevelop is an open-source, no-code, cross-platform 2D/3D and multiplayer game engine designed for everyone. Creators build games visually with an event system (with optional JavaScript), and export in one click to web, Android, iOS, Steam, and desktop. GDevelop is developed in the open by the community and the company behind 4ian/GDevelop.

This file is generated by the API Evangelist enrichment pipeline from the public GDevelop catalog and repository artifacts. GDevelop does not publish an official llms.txt; this is a faithful summary, not a verbatim provider document.

## Product and platforms

- GDevelop is a visual, drag-and-drop game engine (no traditional coding required).
- Supports 2D, 3D, and multiplayer games.
- One-click export/publish to web browsers, Android, iOS, Steam, and desktop.
- Available as a web editor and downloadable desktop app; AI-assisted, lightweight, open-source.

## Notes for agents

- GDevelop is a game-creation product, not a general REST API provider. A backend service exists at api.gdevelop.io (used by the editor for accounts, cloud projects, leaderboards, multiplayer, and the asset store) but it is auth-gated and not publicly documented as an OpenAPI-described API.
- Games built in GDevelop can call external HTTP APIs via the "Send a request to a web page" action documented under the Network feature.
